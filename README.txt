BIO MOTOR — ARCHIVOS DE LA PÁGINA WEB

CONTENIDO
- index.html: página de Inicio.
- servicios.html: página de Servicios.
- contacto.html: página de Contacto.
- styles.css: diseño y adaptación responsive para móviles.
- script.js: menú móvil y preparación del correo del formulario.

CÓMO SUBIRLO A GITHUB
1. Entra en https://github.com e inicia sesión.
2. Pulsa el botón + y elige New repository.
3. Escribe como nombre: bio-motor-web
4. Selecciona Public y crea el repositorio.
5. Pulsa Add file > Upload files.
6. Descomprime este ZIP en tu ordenador y arrastra TODOS los archivos y carpetas
   (index.html, servicios.html, contacto.html, styles.css, script.js y README.txt)
   a la zona de subida de GitHub.
7. Pulsa Commit changes.

IMPORTANTE
- index.html debe quedar en la raíz del repositorio, no dentro de otra carpeta.
- Las fotografías se cargan desde Unsplash y las tipografías desde Google Fonts,
  por lo que se necesita conexión a Internet para ver esos elementos.
- El formulario prepara un email en la aplicación de correo del visitante.
  No almacena datos ni envía información a un servidor.
- BIO MOTOR y sus datos de contacto son ficticios y se han creado para una
  actividad académica.
- Después conecta este repositorio con Vercel para publicar la web.
